# フリフリ・シューティング！ 🎯

カメラの前で **手ぶら** で遊ぶ、体感シューティングゲームです。
✋ パーで狙って、✊ グーで撃つ！ 40秒で何点とれるか競います。
**1人でも2人でも** 遊べて、結果はランキングに自動保存されます。

文化祭の出し物にぴったり。参加者は手に何もつけません。ノートPC1台＋大画面（プロジェクター/テレビ）でOK。
特別な機械もペアリングもネットワークも不要です。

---

## 遊び方（かんたん3ステップ）

### 1. 起動する
- **Windows**: フォルダの中の **`start.bat`** をダブルクリック
- **Mac / Linux**: ターミナルで `sh start.sh`

ブラウザが自動で開きます（開かなければ `http://localhost:8000` を入力）。

> ⚠️ **`index.html` を直接ダブルクリックしないでください。**
> カメラはセキュリティの都合で「直接ひらき」では動きません。必ず上の起動方法を使ってください。

### 2. カメラを許可する
最初に「カメラを使ってよいですか？」と聞かれたら **「許可 / Allow」** を押します。
（推奨ブラウザ：**Google Chrome** または **Microsoft Edge**）

### 3. 遊ぶ
1. **スタート** を押す
2. **1人 / 2人** を選ぶ
3. カメラに手をうつして **はじめる**
4. ✋で狙って ✊で撃つ！ 40秒勝負！

---

## 大画面（プロジェクター）に出すコツ
- 画面の出力は「**複製**」に設定
- ブラウザを大画面側に置き、**F11キーで全画面**
- 2人プレイは、カメラの前に **左右に並んで** 立つ（左の人=赤P1 / 右の人=青P2）

## 明るさが大事
カメラは手を「見て」います。**手がはっきり映る明るさ** を確保してください。
逆光（窓を背に立つ）や暗すぎる場所は苦手です。

## うまくいかないときは
- 手をうまく認識しない → 明るくする／背景をすっきりさせる／感度スライダーを調整
- カメラが使えない → メニューの **「カメラなし（マウスで遊ぶ）」** にチェックすればマウスで遊べます（出し物は止まりません）
- 音が出ない → 最初に画面を一度クリックすると鳴り始めます

## 終了する
黒いウィンドウ（コマンドプロンプト／ターミナル）を閉じれば終了です。

---

## 設定を変えたい人へ（任意）
`js/config.js` を開くと、制限時間・的の数・感度などを数字で変えられます。
むずかしいプログラミングは不要。数字を書き換えて保存し、ブラウザを再読み込みするだけです。

## 文化祭でネットが無い場合（オフライン対応）
標準では手認識のデータをインターネットから読み込みます。
ネットが無い会場では、`models/README.txt` の手順でデータを1回ダウンロードして同梱すれば、
**完全オフライン** で動かせます。

## 音をつけたい人へ（任意）
`assets/` に `bgm.mp3`（ループ用BGM）と `hit.mp3`（命中音）を置くと自動で鳴ります。
無くても、命中音は「ピコッ」と自動生成されるので問題ありません。
